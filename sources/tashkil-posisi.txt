# POSISI TASHKIL
#
# Posisi dasar tashkil sama dengan font Amiri asli. Berkas ini hanya berisi koreksi Anda, satu per baris.
# Setiap baris menggeser tashkil sebuah huruf (atau huruf dalam konteks tertentu) dari posisi aslinya.
#
# FORMAT
#     huruf => atas dx dy  bawah dx dy  | Bold atas dx dy  bawah dx dy
#
#   huruf    Satu huruf Arab = huruf itu di mana pun (semua bentuknya, termasuk ligatur).
#            Dua huruf atau lebih = konteks: huruf-huruf itu berurutan, ditulis dalam urutan mengetik
#            dipisah spasi.
#   atas     geser tanda yang ada DI ATAS huruf       bawah   geser tanda yang ada DI BAWAH huruf
#   dx dy    dx: ke kanan (+) / kiri (-).  dy: ke atas (+) / bawah (-).  Satuan 1/1000 tinggi huruf.
#            Selalu relatif terhadap posisi asli.
#   | Bold   (boleh dihilangkan) angka khusus Bold. Tanpa bagian ini Bold memakai angka yang sama.
#            Medium dan SemiBold otomatis di antara Regular dan Bold.
#
#   atas dan bawah boleh ditulis salah satu atau keduanya. Di bagian Bold, sisi yang tidak ditulis
#   memakai angka Regular.
#
# DI KONTEKS (dua huruf atau lebih):
#   *        Tanda pada huruf yang diberi * yang digeser. Tanpa *, yang digeser huruf PERTAMA.
#   ^  ~  $  _   Boleh ditempel pada huruf: ^ = bentuk awal kata, ~ = tengah, $ = akhir kata,
#            _ = berdiri sendiri (isolated). Tanpa tanda = semua bentuk.   Contoh: ح^ = ha di awal kata.
#            Tanda ini berlaku juga untuk huruf TUNGGAL: ب^ , ب~ , ب$ , ب_ mengatur tiap posisi sendiri-sendiri.
#   [ح ج خ]  Beberapa huruf sekaligus pada satu posisi.
#   Bila beberapa baris cocok pada tanda yang sama, baris dengan huruf paling banyak (paling spesifik)
#   yang dipakai; baris yang lebih umum tidak ditambahkan lagi.
#
# CONTOH (hapus tanda # di depannya untuk memakainya)
#   ب => atas 0 20                              tanda atas semua ب naik 20
#   ب^ => bawah 0 -30 | Bold bawah 0 -40        tanda bawah ب di awal kata turun 30 (Bold: 40)
#   ت ك~ => atas 0 314                          tanda atas ت yang diikuti ك tengah naik 314
#   ل ح* => atas 140 0                          tanda atas ح yang didahului ل bergeser 140 ke kanan
#   [ف ق] [ح ج خ]~* => atas -100 0              tanda huruf ke-2 (ح/ج/خ tengah) setelah ف atau ق ke kiri 100
#
# Setelah mengubah berkas ini jalankan `make` (aturan dibangkitkan otomatis), lalu `sh scripts/make-weights.sh`.
# Ingin melihat hasilnya dulu tanpa mengubah apa pun?  python3 scripts/pratinjau.py -a "baris Anda" "kata contoh"
